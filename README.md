# Village Asset Mapping System

A web-based project for exploring village assets using an interactive map.

## Live Website
[Click here to view the project](https://poornimabshetty50-arch.github.io/Village-asset-mapping-system/)

## Technologies Used
- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap

## Features
- Interactive map
- Asset summary cards
- Category filters
- Asset search

## Project Purpose
To help users explore important village assets such as schools, health centres, water facilities and roads.
